# 证书文件目录

此目录用于存放敏感的证书文件，**不会被提交到 Git 仓库**。

## 微信支付证书

请将以下文件放置到此目录：

- `apiclient_key.pem` - 微信支付商户 API 私钥文件

### 获取方式

1. 登录 [微信支付商户平台](https://pay.weixin.qq.com)
2. 进入 账户中心 -> API安全
3. 申请 API 证书
4. 下载证书压缩包，解压后将 `apiclient_key.pem` 复制到此目录

### 注意事项

- 此目录已在 `.gitignore` 中配置忽略
- 请勿将证书文件提交到版本控制系统
- 生产环境部署时，请确保此目录下有正确的证书文件
